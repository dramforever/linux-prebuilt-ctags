# Prebuilt `tags` file for the Linux kernel

Because I can't find any... It doesn't take *that* long to build but it is kind of annoying.

## Usage

Check the [releases page] for downloads.

[releases page]: https://github.com/dramforever/linux-prebuilt-ctags/releases

## Stability guarantees

As of now there's no stability guarantee on aspects such as:

- Update frequency
- Versions of Linux followed
- Release/tag name
- File name
- Options to universal-ctags

Use with caution for automated downloads.
